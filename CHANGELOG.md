# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-09
### Added
- Initial release of PromptKit.
- `PromptBuilder` with fluent API (`system`, `user`, `assistant`).
- Template engine with variable interpolation and defaults.
- Format enforcers (`json`, `xml`, `markdown`, `list`, `csv`).
- Basic variable validation.
- Zero dependencies.
